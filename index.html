    Questions with question words

    Julia asks a lot of questions. How do we report later what she asked?

    Careful: if the question word is the subject, the word order stays the same. What has happened? → I asked him {q:what} {v:had happened}. (p. 28, l. 8–9)

    How it works

    1. Start: asked or wanted to know (+ person)
    2. The question word stays at the front.
    3. do / does / did disappears.
    4. Subject before verb, like in a statement.
    5. Backshift. Change people and time words.
    6. Full stop, no question mark.
    Pattern
    asked (+ person)+question word+subject+verb …

    Yes/no questions: if or whether

    Some questions have no question word. The answer would be just “yes” or “no”.

    How it works

    1. Start: asked or wanted to know (+ person)
    2. No question word? Use if or whether.
    3. do / does / did disappears.
    4. Subject before verb.
    5. Backshift. Change the people.
    6. Full stop, no question mark.
    Pattern
    asked (+ person)+if / whether+subject+verb …

        Commands and requests

        Someone should do something, or not do it. This is how we report it.

        How it works

        1. told (command) or asked (request) + person
        2. to + infinitive
        3. No backshift.
        4. Change the people.
        5. Negative: not to + infinitive
        6. please disappears.
        Pattern
        told / asked + person+(not) to+infinitive …

          Everything at a glance

          What?PatternExample
          Statement
          said (that)+backshift
          		 I am nine. → She said that {s:she} {v:was} nine.
          Question with a question word
          asked+question word+subject+verb
          		 Where is the museum? → Julia asked {q:where} {s:the museum} {v:was}.
          Yes/no question
          asked+if / whether+subject+verb
          		 Can we go back? → Zoe asked {q:if} {s:they} {v:could} go back.
          Command, request
          told / asked + person+(not) to+infinitive
          		 Don’t worry. → They told me {t:not to} {v:worry}.
          Remember

          Statements and questions need backshift. Commands and requests just use (not) to + infinitive.
